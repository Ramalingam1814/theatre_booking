About This Project

Theatre Ticket Booking System — a frontend-based academic project.

About the Project

CineBook is a frontend-only online theatre ticket booking website built as a college mini/final-year project. It demonstrates a complete real-world booking flow — from browsing movies to seat selection, checkout and booking history — entirely in the browser, using the browser's localStorage for persistence. No backend server or database is used in the current version.

Key Features

  • Browse, search and filter movies by genre and language
  • Detailed movie information page with cast, director and description
  • Theatre, date and show-time selection
  • Interactive, dynamically generated seat map with live price calculation
  • Simulated checkout with form validation and multiple payment methods
  • Auto-generated booking ID and printable digital ticket
  • Booking history with cancellation support
  • Frontend-only login/register system using localStorage
  • Fully responsive design for desktop, tablet and mobile

Technologies Used

HTML5 CSS3 Vanilla JavaScript (ES6) Browser localStorage GitHub Pages
